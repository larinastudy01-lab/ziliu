# 資流 Ziliu

以「知識像水一樣逐漸匯聚」為概念的繁體中文資工研究所備考互動原型。無建置步驟與執行階段套件。

在專案目錄執行 `node serve.mjs`，開啟 http://127.0.0.1:4173 。靜態網站檔案位於 `docs/`。

已加入使用者提供的「1-1 矩陣及矩陣運算」第一階段審閱稿：12 個知識點、12 道例題、35 個閱讀與手寫板塊，以及 7 題小節測驗。其他五科保持空白，沒有捏造學習進度。

支援筆畫壓力、筆色與粗細、橡皮擦、復原與重做、縮放、白底方格／橫線、插入筆記與位置調整、拖曳講義板塊、收藏、題庫篩選、筆記彙整與減少動態效果。主要入口在桌機和平板使用側邊欄，在手機使用底部導覽。

資料保存在瀏覽器 localStorage。沒有帳號、跨裝置同步或伺服器儲存。交卷後鎖定原始手寫作答，另開訂正區。單題重做保留每次作答快照，首次與重做分析分開。

課程資料整理至 `docs/content.js`，與介面分開，詳見 `CONTENT_SCHEMA.md`。本次只有 1-1，沒有補造 1-2、正式大章名稱或大章綜合測驗。審閱稿指出原教材前段尚未完整提供；前置補充在講義中另標示。完成已提供的 1-1 不會標記全章完成。

小節測驗為 5 題單選（各 2 分）及 2 題手寫（各 10 分），總配分 30 分。系統只自動計算選擇題的 10 分；手寫對照詳解、評分重點及自評，不以 AI 批改。測驗與題庫依同一題目 ID 共用作答紀錄。15 題未核實考古題摘要不進入題庫。

數學排版使用本機提供的 KaTeX 0.19.0，包含 MathML；授權見 `docs/vendor/katex/LICENSE`。不依賴外部公式服務。教材 Markdown 使用有限語法並跳脫 HTML，數學連結不啟用信任模式。

閱讀水位只統計「已提供的小節」。沒有作答時顯示「尚未練習」，答對率顯示「—」。不提供使用者 PDF 上傳。

新版本使用 `ziliu-v2` 儲存空間，不沿用舊版示範進度、作答與收藏。舊版由使用者實際書寫的筆記會保留為未分類筆記。筆記與作答不會提交到 GitHub。

執行 `node --check docs/app.js` 與 `node smoke-test.mjs` 可檢查空白科目及 1-1 的閱讀、測驗計分、自評、首次／重做紀錄、筆記與數學式。檢查以輕量 DOM 替身執行實際應用程式，不等同瀏覽器視覺、裝置尺寸或實體觸控筆驗證。

`node scripts/import-la-11.mjs <審閱稿.md>` 可重新轉換本次來源。來源檔僅供轉換，不直接公開；資料記錄檔名與 SHA-256，不包含使用者的本機路徑。匯入器讀取教材資料，不執行文件內的工作流程指示。

主視覺由本地 SVG 光影、曲線、漣漪與水位構成，無外部圖片依賴。字體使用 Google Fonts，離線時以系統 sans-serif 顯示。
